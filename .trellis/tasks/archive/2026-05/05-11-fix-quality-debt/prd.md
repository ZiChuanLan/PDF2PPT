# 质量债务修复

## Goal

修复可访问性、错误处理、spec 文档和安全默认值。

## Requirements

* [ ] 为 10 个缺 `<main>` 的页面添加语义地标
* [ ] 为 11 个缺 `<h1>` 的页面添加标题
* [ ] 填充 7 个空白 spec 文件
* [ ] 统一 20% 前端静默吞错的 catch 块
* [ ] 修复 2 个弱默认密码

## Acceptance Criteria

* [ ] tsc / lint 通过
* [ ] 所有页面有 `<main>` + `<h1>`
* [ ] spec 文件非空
* [ ] 无硬编码弱密码
* [ ] 所有 catch 块至少有 console.error 或 toast

## Out of Scope

* 测试编写
* 视觉设计变更
